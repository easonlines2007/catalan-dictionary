# Català — Pocket dictionary

English · [中文](README.zh-CN.md) · [Español](README.es.md)

I came to Barcelona to study, but my Catalan is pretty terrible—so I made a
Catalan–Chinese–Spanish dictionary to help myself out. Feel free to use it!

A mobile-friendly PWA with pronunciation, word-form lookup, saved words and
offline access. It covers about 97,000 Catalan entries; Chinese meanings are
available for a small, reviewed subset. No account is needed.

[Try the app](https://catalan-dictionary-pwa.vercel.app)

## Run locally

With Node.js 22:

```bash
npm ci
npm run dev
```

Verify with `npm test`, `npm run lint` and `npm run typecheck`.
