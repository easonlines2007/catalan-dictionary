# Català — Diccionario de bolsillo

[English](README.md) · [中文](README.zh-CN.md) · Español

Vine a Barcelona a estudiar, pero mi catalán deja bastante que desear, así que
hice un diccionario de catalán, chino y español para apañármelas. ¡Usadlo libremente!

Una PWA para el móvil con pronunciación, búsqueda de formas, favoritos y acceso
sin conexión. Incluye unas 97.000 entradas en catalán; las traducciones al chino
cubren por ahora una pequeña selección revisada. No hace falta registrarse.

[Abrir el diccionario](https://catalan-dictionary-pwa.vercel.app)

## Uso local

Con Node.js 22:

```bash
npm ci
npm run dev
```

Comprobaciones: `npm test`, `npm run lint` y `npm run typecheck`.
